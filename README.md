# 🚀 C++ Distributed Key-Value Store

A simple, fast, and lightweight in-memory Key-Value store built in C++ from scratch.

## 📌 About The Project
This is an in-memory database project (similar to Redis) designed to handle basic data storage operations and learn low-level systems programming in C++.

## 🛠️ Features & Development Plan
- [x] Basic Key-Value operations (`SET`, `GET`, `DELETE`)
- [ ] Multi-threading for concurrent users
- [ ] Saving data to disk (File I/O)
- [ ] Basic client-server TCP networking

## 🚀 Tech Stack
* **Language:** C++17
* **Tools:** GCC Compiler, Git
